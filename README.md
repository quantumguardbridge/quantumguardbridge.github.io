# Quantum Guard Bridge website

This package contains a bilingual static website for GitHub Pages.

## Files
- `index.html` — homepage in English and French.
- `contact.html` — contact page with email, phone, and LinkedIn links.

## Deploy on GitHub Pages
1. Create a public repository.
2. Upload both HTML files to the repository root.
3. In Settings -> Pages, choose `Deploy from a branch`.
4. Select `main` and `/root`.
5. Save and wait for the site URL.
